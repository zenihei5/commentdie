# クリア画面第2版 仕上げ調整設計

## 目的

修正後のクリア画面で残っている次の3点だけを整える。

- 完走サブコピーと「配信サマリー」帯の重なり
- PP報酬カードの合計行の詰まり
- ランキング登録表示の弱さ

報酬計算、ランキング登録判定、セーブ、画面遷移、敗北画面には変更を加えない。

## 1. 完走サブコピー

現状は完走サブコピーのベースラインが `y = 224`、配信サマリー帯の開始位置が `y = 220` で、設計値の時点で重なっている。

### 修正

- 完走タイトル「配信完走！」を現在より約8px上へ移動する。
- サブコピー「最後まで配信を走り切った！」のベースラインを `y = 210～212` 程度へ移動する。
- サブコピーの文字サイズは `18px` を基準とする。
- 配信サマリー帯の上端との間に、描画上最低6pxの空きを確保する。
- 他の結果状態の見出し位置は必要以上に動かさない。

推奨初期値（現在のパネル座標系）：

```text
完走タイトル: panel.position + Vector2(94, 108)
完走サブコピー: panel.position + Vector2(98, 138)
```

## 2. PP報酬カード

現状は最終内訳行と合計行のベースライン差が約12pxしかなく、区切りもないため、合計が内訳へ混ざって見える。

### 詳細カードの高さ配分

全体高は変えず、次の配分へ変更する。

```text
配信ハイライト: 104px
PP報酬:          116px
最終ビルド:      128px
ランキング:       60px
カード間余白:      8px x 3
```

合計は従来と同じ432pxで、詳細領域からはみ出さない。

### PP報酬内部

- 内訳は最大3行×2列を維持する。
- 1列表示・2列表示とも、内訳の行間は18pxを基準とする。
- カード下部に合計専用領域を最低22px確保する。
- 内訳と合計の間へ1pxの淡い区切り線を描く。
- 合計値は `15～16px`、右寄せ、従来より少し濃いオレンジで表示する。
- 「合計」と数値の間には半角スペース相当以上の空きを残す。
- 保存失敗・受取済み・報酬なしの文言と色の意味は変えない。

推奨配置：

```text
内訳ベースライン: local y = 44, 62, 80
区切り線:         local y = 93 前後
合計ベースライン: local y = 109 前後
```

合計行を新しい入れ子カードやピルにはせず、区切り線と文字の強弱で整理する。

## 3. ランキング登録表示

登録成功時は結果画面内の小さな達成演出として、未登録時との見た目の差を明確にする。

### 登録済み

- 現在の60pxカード高は維持してよい。
- カード外側へ低透明度の金色グローを1層追加する。
- 本体は白～淡い金の明るい面、金色3px境界を使用する。
- 王冠または表彰台アイコンを40px前後へ拡大する。
- 順位を固定幅58px程度の領域へ `26～28px` で大きく表示する。
- 「ランキング登録！」を `15～16px` へ強める。
- 補助文を `12～13px` とし、順位と見出しより弱くする。
- 左右端へ小さな静止キラキラを1～2個置いてよい。
- 常時点滅やループアニメーションは追加しない。

### 未登録・圏外

- 紫系の控えめなカードを維持する。
- 登録済み用の金色グロー、祝福キラキラ、強い順位表示は出さない。
- `rankingRegistered` と既存順位データを唯一の判定元とし、見た目の都合で成功扱いを推測しない。

## 4. 検証

### 静的テスト

- 完走サブコピーの描画下端が配信サマリー帯の上端を越えない。
- 詳細カード4枚と3つの余白の合計が詳細領域高と一致する。
- PP内訳が1～6件の全ケースで合計専用領域へ侵入しない。
- 登録済みと未登録でカード表示モデルが明確に分岐する。
- `git diff --check` が通る。

### 目視

`1600x900` で次を確認する。

- 「最後まで配信を走り切った！」が完全に読める。
- PP合計が内訳の続きではなく、集計として一目で分かる。
- ランキング登録済みが右側キャラクターに負けない達成情報として見える。
- 詳細カードや下部ボタンの位置が崩れていない。
