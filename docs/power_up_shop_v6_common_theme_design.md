# パワーアップショップ第6版 共通テーマ統合設計

## 1. 仕様確認結果

第6版は実装可能。購入、保存、リセット、入力、カード順、マスコット状態、画面遷移には変更を加えず、表示テーマだけを更新する。

ただし、オプション画面は `game.gd` の Canvas 直描画、ショップは Control と StyleBox で構成されている。そのため、Theme/StyleBoxリソースだけを直接共有するのではなく、両方から利用できる共通パレットとStyleBox生成APIを追加する。

## 2. 共通スタイル層

`scripts/ui/common_light_ui_style.gd` を追加し、次を一元管理する。

- 第6版の共通カラーパレット
- 大型白パネル、通常行、選択行、戻る、初期化、値欄のStyleBox生成
- ホバー、押下、フォーカス時の派生色
- 明色UI用の影、枠幅、角丸

`game.gd` のオプション描画は、現在の座標、サイズ、操作、描画順を変えず、色リテラルだけを共通スタイルへ置き換える。これによりオプション画面の見た目を基準として固定しながら、ショップと同じ色定義を利用できる。

`power_up_shop_visual_style.gd` はショップ固有のtier、ランプ、カード状態を残し、共通色と共通部品は `CommonLightUiStyle` へ委譲する。共通色を両ファイルへ重複定義しない。

StyleBoxは画面初期化時または状態変更時だけ生成する。毎フレーム生成しない。共有StyleBoxを個別ノードで変更する場合は `duplicate(true)` してから変更し、別UIへ変更を伝播させない。

## 3. 画面構造

既存コードとテストが参照する `SafeAreaMargin/MainCenter/ShopContent/...` のNodePathは維持する。

`MainCenter` の子として、`ShopContent` より前に装飾用の `MainPanelBackdrop: PanelContainer` を追加する。CenterContainer内で両者を中央配置し、白パネルをShopContentの背面へ重ねる。ShopContentを別ノードへreparentしない。

```text
SafeAreaMargin
└── MainCenter
    ├── MainPanelBackdrop
    └── ShopContent
```

追加・変更する表示要素:

- `BackgroundWash`: `#F7EEFF`、alpha 0.15を初期値とする
- `MainPanelBackdrop`: 半透明の大型白パネル
- `TitleArea/Description`: 「配信ポイントを使って能力を強化できます」
- `MascotGlow`: 四角いColorRectは非表示または削除
- 必要ならマスコット足元へ低透明度の楕円影を追加する。画像素材はすでに透過済みなので加工しない

`MainPanelBackdrop` は画面遷移時にShopContentと同じXオフセットで動かす。`power_up_shop_screen.gd::_common_front_transition_nodes` に含め、TransitionVeilだけは従来どおり画面固定とする。

## 4. 1600x900レイアウト

- 大型パネル: 1400 x 810を基準、中央配置
- ShopContent: パネル内側へ左右40px以上、上下24px以上の余白
- ヘッダー、タブ、Body、フッターの順序は維持
- フッターのButtonノード順は変更しない。キーボード/ゲームパッドの論理フォーカス順を維持する

プロジェクトは1600x900の論理解像度を `canvas_items` で拡縮している。1280x720から2560x1440の確認は、まず論理レイアウトを保った出力スケーリングとして行う。テストでControl自体を小さくする場合だけ既存compact分岐を使い、次の順で余白を縮小する。

1. パネル外側余白
2. ヘッダーとセクション間隔
3. カード間隔
4. 詳細パネル内余白
5. フッター高さ
6. マスコット

文字サイズは最後に調整し、カード名、価格、ギフト祈願の2行比較を切らない。

## 5. 表示スタイル

### 共通

- メインパネル: `#FFF9FD` alpha 0.93、枠 `#F0A3C9` 3px、角丸30px、弱い紫影
- 主文字: `#3F2C4E`
- 副文字: `#765F78`
- 薄い文字: `#96839A`
- 区切り: `#E8D5E5`
- 英字タイトル: `#EF6BA4`
- 日本語タイトルは濃紫。白文字を使わない

### ヘッダー

- 総強化Lvのトラックを `#E8DDEB` へ変更
- 塗りはピンクから水色の明色グラデーション。実装がStyleBoxFlatの場合は、共通APIの明色ブレンドを使用し、濃色バーへ戻さない
- PPカプセルは `#FFFDF5`、金枠、濃紫ラベル、金色の大きな数値

### タブ

- 未選択: 白背景、薄紫枠、濃紫文字
- 戦闘選択: `#EE75AA`、白文字
- サポート選択: `#62BED8`、白文字
- 論理フォーカスは枠幅または淡い外側発光で示し、濃紺へ戻さない

### カード

- 通常: 白から固有の極薄色、薄紫枠2px、角丸18から22px
- 選択: カテゴリ色3から4px、淡い発光、scale 1.025
- 現在の選択時 `+8px` 右移動を廃止する
- 現在のscale 1.04を1.025へ抑える
- 強い黒紫影を廃止し、共通の弱いカテゴリ発光へ変更する
- 左端アクセントは4から6pxを維持し、カテゴリ判別を優先する

価格表示:

- 購入可能: 金色系
- PP不足: 淡いピンク系
- MAX: 金色系
- 購入可能カードを警告色にしない

### 詳細パネル

- 全体: `#FFFDFE`、カテゴリ色枠2から3px、角丸22から28px
- 戦闘ヒーロー: `#F6C4D9` から `#F0A4C6` 相当の低彩度色
- サポートヒーロー: `#D2F0F5` から `#A7DDEB` 相当の低彩度色
- 強化名は戦闘 `#4B2945`、サポート `#29495B`
- 情報領域は白、境界は `#E8D8E7`
- 現在効果は薄紫、次Lvは淡い金色
- ギフト祈願の2行表示、余白、font size分岐は変更しない

### 購入ボタン

- 購入可能: 現在カテゴリの明色
- PP不足: 薄紫グレー
- MAX: 淡い金色
- 文言、disabled判定、購入ロックは変更しない

### マスコット

- `listener_summon.png` は透過済み。画像変更や単色抜きは不要
- 四角く見える `MascotGlow` を非表示にする
- 吹き出しは白背景、カテゴリ色枠、濃紫文字
- 既存の状態判定、拡縮リアクション、予約済み右下領域は維持する

### フッター

- Footerは透明または `#FFF9FD`、上辺のみ淡いピンク紫
- 戻る: `#EEF8FF`、枠 `#258EBE`、文字 `#2586B5`
- 全強化リセット: `#FFF4F8`、枠/文字 `#E93681`
- InputHintsは副文字色、背景は透明
- 選択時は同系色の淡い発光を追加する。通常時を濃紺にしない

## 6. オプション画面への影響範囲

オプション画面は共通定数を参照するようにするが、次を変更しない。

- パネル座標とサイズ
- 項目の行間
- アイコン、文言、フォントサイズ
- スライダー、トグル、選択欄の操作
- フォーカス順
- タイトル/ポーズからの遷移

共通化前後でオプション画面のスクリーンショット差分が実質的にないことを確認する。意図しない色変化が出る場合は、オプションの現行色を共通定数の正とする。

## 9. テスト

自動/静的確認:

- 共通パレットをオプションとショップが同じ定義から参照する
- MainPanelBackdropが存在し、背景とShopContentの間にある
- MainPanelBackdropが共通画面遷移の移動対象に含まれる
- BackgroundWashが `#F7EEFF` alpha 0.12から0.18の範囲
- タイトル、PP、タブ、Footerが濃紺スタイルを参照しない
- 戻る/リセットの通常・選択スタイルが青/ピンクである
- 選択カードのscaleが1.025以下、X移動が0
- MascotGlowが表示されない
- direct open/close、入力テスト、購入回数テストが維持される
- ギフト祈願の比較欄が2行表示のまま
- `git diff --check`

視覚確認:

- 1280x720、1600x900、1920x1080、2560x1440
- 戦闘カテゴリ、サポートカテゴリ
- 購入可能、PP不足、MAX
- マスコット通常、購入成功、MAX
- リセット確認ダイアログ
- titleからの入退場アニメーション中もパネルと内容が一体で移動する

Godot Editorが起動中の場合は新規Godotプロセスを起動しない。静的確認まで行い、視覚確認は既存エディタ終了後の未実施項目として明記する。

## 10. 完成条件

ショップの機能、配置、入力経路を保ったまま、背景の上に半透明白パネルが成立し、濃紺のタブ、PP、Footer、強いヒーロー色が明色テーマへ置き換わっていること。オプション画面の見た目と挙動は変えず、両画面が同じ共通パレットと部品定義を利用していること。
